Connect Google Sheets

Sync your calendar data across all devices. You only need to set this up once.

  2. Click Extensions → Apps Script
  3. Paste the Apps Script code (from the JS file)
  4. Click Deploy → New Deployment → Web App
  5. Set access to "Anyone" → Deploy
  6. Copy the Web App URL and paste below
